# Nova AI

**AI-Powered Image Captioning with Arabic Translation and Text-to-Speech**

Nova AI is a web application designed to help blind and visually impaired users access visual content through AI-generated image descriptions in Arabic.

The application allows users to upload an image, generate a short description of its content, translate the description into Arabic, and listen to it using text-to-speech technology.

## Features

- Image upload and preview
- AI-powered image captioning
- English-to-Arabic translation
- Arabic text-to-speech using the browser
- Audio playback and stop controls
- Responsive Arabic user interface
- Basic file validation

## Technologies Used

- **Python** – Backend programming
- **Flask** – Web application framework
- **BLIP** – AI image caption generation
- **MarianMT** – English-to-Arabic translation
- **HTML** – Web page structure
- **CSS** – User interface styling
- **JavaScript** – User interaction and text-to-speech

## How It Works

1. The user uploads an image.
2. BLIP generates an English description.
3. MarianMT translates the description into Arabic.
4. The application displays the Arabic description.
5. The user can listen to the description using the browser's speech synthesis functionality.

## Project Purpose

Nova AI aims to make visual information more accessible by combining computer vision, machine translation, and speech synthesis in a simple web application.

## Limitations

Nova AI is a functional prototype. AI-generated descriptions may be inaccurate, particularly for complex images. The application is not intended for safety-critical situations.
